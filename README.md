Тема проекта: 6-осевая сервоприводная рука.
Состав участников: Жуланов Павел, Покидов Игорь, Барцев Арсений - группа ИПР-24-1б.

Цель проекта: предварительная подготовка и сборка базовых компонентов для будущей разработки роботизированного манипулятора.
Задачи проекта: Разработать промышленный манипулятор с расширенной рабочей зоной для нестандартных задач.

  1.1 Проблематика существующих решений

• Ограниченная мобильность стационарных манипуляторов: Классические промышленные руки закреплены на одном месте, что сужает их рабочую зону до длины своего захвата.
• Низкая доступность и высокая сложность: Сложные программируемые роботы имеют высокую стоимость и требуют специальных знаний для настройки и эксплуатации.
• Негибкость управления: Многие системы имеют жёстко заданные алгоритмы и не позволяют оперативно адаптироваться к нестандартным задачам или удалённому управлению.

1.2 Преимущества проекта 6-осевой сервоприводной руки с дистанционным управлением

• Универсальность и доступность: Использование стандартных компонентов (Arduino, сервоприводы) делает сборку и модификацию доступной для образовательных целей, хобби и прототипирования.
• Гибкость управления: Возможность прямого пошагового управления каждым суставом (через Bluetooth) позволяет выполнять как простые, так и сложные манипуляции, адаптируясь к задаче в реальном времени.
• Потенциал для автономности: Базовая платформа (контроллер Arduino, датчики) позволяет развивать проект в сторону программирования и записи последовательностей движений.
• Образовательная ценность: Проект наглядно демонстрирует принципы робототехники, кинематики, микроконтроллерного программирования и беспроводной связи.

  2. Сценарии применения
2.1 Образовательный демонстратор и тренажёр:
• Изучение основ робототехники, механики и программирования.
• Визуализация принципов работы промышленных манипуляторов.
• Платформа для экспериментов с алгоритмами управления и компьютерным зрением (при доработке).
2.2 Прототип помощника для манипуляций в недоступной среде:
• Моделирование операций по переносу небольших объектов в условиях, где присутствие человека нежелательно или невозможно
• Дистанционный сбор предметов.
2.3 Базовый модуль для более сложных роботизированных комплексов:
• Рука может быть установлена на мобильную платформу (робот-тележка), создавая аналог гибридной системы доставки, но для операций внутри помещения.

  3. Технические требования
Степени свободы: 6 осей: основание, плечо, локоть, запястье (2 оси), захват.
Приводы: 6 сервоприводов + шаговый двигатель, 2 сервопривода синхронно работают на локтевом суставе для увеличения момента. Шаговый двигатель вращает основание.
Система управления: Микроконтроллер Arduino (Uno/Nano) + драйвер PCA9685, PCA9685 обеспечивает точное управление несколькими сервоприводами по шине I2C.
Связь: Bluetooth (HC-05/HC-06), дистанционное управление со смартфона или ПК.
Программная логика: Пошаговое управление суставами, каждой команде (букве) соответствует движение конкретного сустава на фиксированный угол (increment).
Питание: Внешний источник 5-6В, необходимо для стабильной работы всех сервоприводов одновременно.

  4. Алгоритм выполнения задачи (на примере дистанционного управления)
1 Инициализация системы: Подача питания, установка сервоприводов в "парковочную" позицию.
2 Установка соединения: Подключение пульта управления (смартфона с терминалом Bluetooth) к модулю HC-05.
3 Цикл управления:
• Оператор отправляет буквенную команду (например, 'C' для поднятия плеча).
• Контроллер Arduino принимает команду через последовательный порт.
• Вызывается соответствующая функция движения (shoulderServoBackward()).
• Функция проверяет, не достигнут ли механический предел, и отправляет новый сигнал на драйвер сервопривода.
• Сервопривод поворачивается на заданный угол, текущая позиция обновляется в переменной.
• Рука готова к приёму следующей команды.
4 Завершение работы: Возврат в "парковочную" позицию (при необходимости) и отключение.

  5. Пульт управления (Интерфейс оператора)
Управление реализовано через терминал Bluetooth, что является гибким и минималистичным решением.
• Аппаратная часть: Стандартный модуль Bluetooth HC-05/06, подключённый к UART пинам Arduino.
• Программный интерфейс: Любое приложение-терминал на смартфоне или ПК (например, Arduino Bluetooth Controller, Serial Bluetooth Terminal).
• Схема управления (сопоставление команда-действие):
• S / O → Вращение основания влево / вправо (шаговый двигатель).
• c / C → Опускание / поднятие плеча (сервопривод 2).
• p / P → Опускание / поднятие локтя (синхронная работа сервоприводов 0 и 1).
• G / U → Наклон запястья 1 вниз / вверх (сервопривод 3).
• L / R → Вращение запястья 2 против / по часовой стрелке (сервопривод 4).
• f / F → Закрытие / открытие захвата (сервопривод 5).
Для удобства в терминальном приложении можно создать кнопки-макросы, каждая из которых отправляет свою букву.
